# 문장수집 V1

모바일에서 책 페이지를 촬영하거나 사진을 불러온 뒤, 원하는 문장 영역을 손가락으로 드래그해 OCR로 추출하고 저장하는 PWA입니다.

## 주요 기능
- 모바일 카메라 촬영
- 사진첩 불러오기
- 손가락 드래그로 문장 영역 선택
- 선택 영역 OCR (한글+영문)
- 밑줄 자동 후보 탐색(실험 기능)
- OCR 결과 직접 수정
- 책 제목 / 페이지 / 저자 / 메모 / 태그 저장
- IndexedDB 기기 저장
- 저장 문장 검색 / 복사 / 삭제
- PWA 설치

## 데이터 저장
V1은 서버 DB를 쓰지 않습니다. 저장한 문장은 각 사용자의 브라우저 IndexedDB에만 저장됩니다. 따라서 서로 다른 휴대폰의 데이터는 서로 섞이지 않습니다.

## 공개 배포
GitHub Pages용 워크플로가 포함되어 있습니다. Pages가 GitHub Actions 소스로 활성화되면 자동 배포됩니다.
